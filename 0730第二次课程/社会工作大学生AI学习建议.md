建议下一阶段不要急着学“编程”，而是学习如何用 VS Code + Claude Code 完成社会工作专业的真实任务。路线应以项目为中心。

### 推荐学习顺序

1. **文件与工作区管理**
   学会文件夹、Markdown、PDF、CSV 的基本概念，以及让 Claude 创建、读取和修改项目文件。目标是完成一份结构清晰的课程作业目录。

2. **AI协作与结果核验**
   学会提供背景、目标、限制和交付格式；查看 Claude 修改了哪些文件；识别幻觉、错误引用和过度推断。重点掌握：
      提出任务 → 查看计划 → 审阅修改 → 核查来源 → 接受成果

3. **文献检索与研究综述**
   用公开文献完成：
   
   * 研究问题拆解；
   * 检索关键词设计；
   * 文献摘要和比较；
   * 观点—证据对应；
   * 引用真实性核验。
   
   AI可以帮助整理文献，但不能凭空生成参考文献。

4. **社会工作专业文档**
   使用虚构或彻底匿名化的材料，练习：
   
   * 访谈提纲；
   * 个案记录；
   * 需求评估；
   * 服务计划；
   * 小组活动方案；
   * 社区调研问卷；
   * 项目总结和评估报告。
   
   不应把姓名、身份证号、联系方式、健康信息、家庭矛盾等真实服务对象资料发送给外部大模型。

5. **公共数据与表格分析**
   学会处理 CSV/Excel：
   
   * 理解行、列和字段；
   * 筛选、排序和去重；
   * 计算比例和分组统计；
   * 制作图表；
   * 解释相关性与因果性的区别。
   
   可以选用人口老龄化、社会救助、残障服务、社区资源或刚才讨论的新能源车数据。新能源车也能形成社会政策题目，例如：
   
   > 英国公共充电设施分布与地区贫困程度之间的关系。
   
   这涉及交通公平、空间排斥和公共服务可及性，与社会工作并非无关。

6. **版本管理与可追溯性**
   掌握最少量的 Git 概念：
   
   * 修改前后差异；
   * 保存一个版本；
   * 恢复误改文件；
   * 记录数据和报告的形成过程。
   
   不必先学习复杂命令，重点是“能看懂改了什么、能撤回”。

7. **基础自动化**
   当表格操作已经熟悉后，再学习少量 Python，让 Claude 帮助完成重复任务：
   
   * 合并多个 CSV；
   * 批量清理字段；
   * 生成统计表；
   * 重复生成图表；
   * 检查缺失值。
   
   学生不必从语法教材开始，而应从一个真实、可验证的小任务开始。

8. **可复用工作流**
   最后把稳定方法整理成项目说明、模板或 Skill，例如：
      社区调研数据检查流程
      文献真实性核查流程
      匿名化个案记录整理流程
      课程论文结构审查流程

### 最适合的第一个项目

建议用一个不含个人敏感信息的公开数据项目，最终形成：
    research-project/
    ├── README.md          研究目标与操作说明
    ├── data/              原始数据
    ├── analysis/          分析过程
    ├── charts/            图表
    ├── sources.md         来源记录
    └── report.md          最终报告

学习成果不是“和 AI 聊了很多”，而是得到一份来源清楚、过程可追溯、可以人工复核的研究报告。

在正式设计第一课前，需要先确定学习使命：这位学生主要想提升的是**课程论文与科研、社会工作实务，还是未来就业能力**？三种方向的后续课程会明显不同。
